# Демо Ustoz

Демо приложения Ustoz (рабочее название): короткие занятия с птицей Хумо для детей 3–7 лет по программе «Ilk qadam» и пример того, как приложение подбирает занятия под ребёнка.

**Это демо для взрослых.** Задания написаны ИИ и ещё не проверены педагогом. Детям не показывать до проверки методистом. Голос Хумо — черновой синтез речи.

Демо ничего не отправляет в интернет: прогресс хранится только в браузере того, кто его открыл.

Здесь лежит только собранный сайт; он обновляется из закрытого репозитория проекта.
